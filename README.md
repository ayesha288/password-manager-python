# Password Manager

## About the Project

This is a simple Password Manager that I built using Python and Tkinter. I created this project to improve my Python skills and learn how desktop applications work.

The application allows users to generate passwords, save login credentials for different websites, and store the data in a JSON file. Users can also search for previously saved passwords.

While building this project, I learned about GUI development, file handling, JSON, functions, dictionaries, and exception handling in Python.

## Features

* Generate random passwords
* Save website credentials
* Store multiple accounts in a JSON file
* Search for saved passwords
* Simple graphical user interface using Tkinter

## Technologies Used

* Python
* Tkinter
* JSON
* Random Module
* File Handling

## How to Run

1. Make sure Python is installed on your computer.
2. Download or clone this repository.
3. Open the project folder.
4. Run the following command:

python main.py
